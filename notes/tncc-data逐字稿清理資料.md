# `../tncc-data`：第四屆議事錄逐字稿清理資料

> 探索日期：2026-10-13。repo 最後 commit 2026-09-04（加入第 6 次定期會、第 10 次臨時會）。流程細節寫在該 repo 的 `CLAUDE.md`，這裡只記和觀測站有關的部分。

## 這個 repo 做了什麼

把議會公布的議事錄（Word 逐字稿為主，只有 PDF 時用舊的 PDF 路徑）轉成「一列一段發言」的 CSV。

```
raw/<會期>/*.docx ──process_docx.py──▶ input/<檔名>.txt ──人工修正──▶ cleaner.py ──▶ output/csv/<標題>_output.csv
                                                                                   output/txt/<標題>.txt
```

- 人工修正的重點：補第一行完整標題（含民國日期）、修「行尾沒標點導致前一句黏進下一位發言人名字」、合併上下午兩檔。
- `address-book/output/csv/address_book.csv`：第四屆議員通訊錄（職稱、黨籍、姓名、英文名、選區涵蓋的行政區、服務處地址電話）。

## CSV 格式

```
speaker,content
主席鄭佳欣議員,會議開始，臺南市政府黃偉哲市長、尤秘書長、…
蔡育輝議員,主席，會議詢問，時間先不要計算。
黃偉哲市長,可不可以把那個比較不配合的局處首長告訴我們，馬上回去處理。
```

- 會期、場次、日期只在檔名（＝第一行標題）裡，例：`第4屆第6次定期會市政總質詢2025年10月23日(第2次會議)_output.csv`。
- 發言人已正規化成「姓名＋職稱」：議員是「蔡育輝議員」，官員保留局處，如「民政局姜淋煌局長」「體育局陳良乾局長」，可以直接推出「質詢相關局處」。

## 要接到觀測站還缺什麼

和〈資料格式〉的 Sheet 欄位對照：

| Sheet 欄位 | tncc-data 有沒有 | 補法 |
|---|---|---|
| 議員、選區 | 有發言人，選區要用 `councilor-map.json` 比對 | 去掉「議員」二字後比對 `abbr` |
| 質詢日期 | 大多在檔名；**29 份市政總質詢／業務報告的檔名沒有日期**（多數是第 1 次定期會，如「市政總質詢(第10次會議)」） | 從議會日程表或議事錄目錄補 |
| 質詢內容（摘要）、質詢相關局處 | 沒有，CSV 是一段一段發言，不是一題一列 | LLM 把同一位議員的連續發言拆成議題並摘要；局處參考回答官員的局處 |
| 發言開頭2句話 | 可以從議員該議題第一段發言直接截取 | — |
| 議事錄頁碼開頭 | 沒有 | 拿發言開頭兩句話到該次定期會 PDF 全文比對（第 6 次已驗證可行，見〈第四屆資料更新路徑〉） |

## 資料品質要注意的地方

- **檔名不一致**：13 份檔名沒有用「第4屆第N次…」開頭，例如 `議員質詢順序：蔡育輝-李中岑-蔡淑惠(聯合質詢)_output.csv`、`F第4屆第3次定期會市政總質詢…`、`臺南市議會第4屆第2次定期會會議紀錄…`。這些是標題行沒修好，用檔名判斷會期會漏掉。
- **發言人欄還有黏行殘留**：以「議員」結尾的發言人有 132 種，第四屆議員只有 57 位。多出來的是前一句黏進名字（「好郭鴻儀議員」「這可以來檢討看看，王宣貿議員」）、請假名單整段被當成發言人、「主席○○議員」等。接到觀測站時，只接受能完全對上 `councilor-map.json` 的名字，其餘列出來回 tncc-data 修中間檔。
