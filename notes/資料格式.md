# 資料格式

> 探索日期：2026-10-13。路徑都相對於 `tcw-ui/`。範例值取自 repo 現有檔案。

## 屆次與議員 id

- 屆次 key：`3rd`（2018–22）、`4th`（2022–26）。網址、資料夾、`round-defs.js`、`misc.json` 都用這個 key。
- 選區 id：`1st` … `13th`，對照「第一選區」…「第十三選區」（`libs/defs.js`、`tools/utils.js` 各有一份）。
- 議員 id：官網議員頁網址 `councilorpage.asp?mainid=63ECF425-FD64-…` 中 `mainid` 的第一段 8 碼（如 `63ECF425`）。**同一人換屆後 id 不同**（例：蔡育輝第三屆 `63ECF425`、第四屆 `053E553A`）。

## `tools/round-defs.js`：每屆的資料來源設定

```js
'3rd': {
  councilorPageId: '09243431-…',   // 官網「議員資訊網」的 orcaid
  sheetUri: 'https://docs.google.com/…/pub?single=true&output=csv',
  sheetList: [
    { sheetId: '1909562558', type: '定期會', round: 1 },
    { sheetId: '956807492',  type: '定期會', round: 1, postfix: '業務' },
    …                                      // 到 round 6
  ]
},
'4th': { councilorPageId: 'C56635AE-…' }   // 沒有 sheet，所以第四屆沒有質詢資料
```

`sheetId` 是 Google Sheet 分頁的 `gid`。`round` 是第幾次定期會，`postfix: '業務'` 表示「市政府業務報告及質詢」那一張分頁（沒有 postfix 的是市政總質詢）。

## `content/council/{屆}/district-map.json`

以選區 id 為 key：

```json
"1st": {
  "districtTitle": "第一選區",
  "townList": ["後壁", "白河", "東山", "鹽水", "新營", "柳營"],
  "districtId": "1st",
  "districtQuota": "6",
  "councilors": [
    { "id": "63ECF425", "name": "蔡育輝", "abbr": "蔡育輝", "party": "中國國民黨",
      "bgUrl": "/img/3rd/5be63922df082c0e3a0c5bacc416150d.jpg",
      "pageLink": "https://www.tncc.gov.tw/councilorpage.asp?mainid=63ECF425-…" }
  ]
}
```

- `townList`：區名去掉「區」字；單字區名和「中西」保留「區」字（如 `"東區"`、`"中西區"`）。原住民選區的 townList 含「原住民」，畫地圖時視為全台南。
- `abbr`：去掉英文字母和間隔號的名字，用來和 Sheet 中的議員名比對。
- `party`：一律存 `partyList.json` 裡的全名。
- `bgUrl`：照片下載後存在 `static/img/{屆}/{md5(原始網址)}.{副檔名}`，寬度超過 640px 會縮小。

## `content/council/{屆}/councilor-map.json`

以議員 id 為 key，內容是 `district-map.json` 的議員物件再加上 `districtId`、`districtTitle`、`townList`。第三屆 58 人、第四屆 57 人。

## `content/council/{屆}/missing-councilor-list.json`

官網上已經查不到、但要保留的議員（例：第三屆的洪玉鳳，id `f07e82f`，照片手動放在 `static/img/洪玉鳳-f07e82f.jpg`）。`get-councilors.mjs` 跑完後會把這份清單合併進兩個 map。

## `content/council/{屆}/meta-第N選區.md`（CMS 編輯）

Frontmatter 放各議員的補充資料，key 是 `councilor-{議員id}`；正文是選區情報（Markdown）。

```yaml
councilor-81919CFD:
  job-history: 台南市議會第3屆議員。
  job-period: 完整          # 完整／已辭職／已停職／已解職／遞補任職／補選任職
  misc-title: 政治關係      # 空白則整欄隱藏
  misc-content: 父親為為現任五條港里里長沈廉哲
```

`static/admin/config.yml` 裡每個選區、每位議員都要**手動列一行** `councilor-{id}`，議員名單有變（遞補、補選）時要一起改。

## `content/council/{屆}/sayit/{議員id}.json`：每位議員的質詢

```json
{
  "id": "E4C9B92F",
  "sayit": [
    {
      "relatedOrgs": ["工務局", "都發局"],
      "summary": "提高中低收入戶老人重症住院看護補助費用。",
      "editorNote": "",
      "say": "首先第一個議題要談的是「醫」的部分(…)",
      "date": "2019-04-23",
      "type": "定期會",
      "round": 1,
      "src": [174]
    }
  ],
  "stats": { "org": [{ "name": "工務局", "count": 14 }] }
}
```

| 欄位 | 來源（Sheet 欄位） | 用途 |
|---|---|---|
| `summary` | 質詢內容 | 卡片標題、搜尋 |
| `say` | 發言開頭2句話 | 卡片內文、PDF 開啟後的高亮關鍵字（取第一句，至少 12 字） |
| `relatedOrgs` | 質詢相關局處（以「、」或換行分隔，「無」會被濾掉，別名依 `departmentBrief.json` 換成簡稱） | 分類、統計 |
| `editorNote` | 編按 | 卡片附註 |
| `date` | 質詢日期，空白時沿用上一列的日期 | 排序 |
| `type`／`round` | 由 `round-defs.js` 的分頁設定帶入 | 決定 PDF 路徑 |
| `src` | 議事錄頁碼開頭（「p.59」「P59、60」都可） | **PDF 頁碼**，`src[0]` 用來開原文 |

第三屆共 13,026 筆。

## `content/council/{屆}/sayit/stats.json`

```json
{ "all": { "org": [{ "name": "教育局", "count": 1359 }, …] },
  "1st": { "org": [...] }, …, "13th": { "org": [...] } }
```

## 第三屆 Google Sheet 欄位（人工編碼）

由台南新芽閱讀議事錄後填寫。實際表頭（第 5 次定期會業務報告分頁，gid=618060648）：

```
議案屆次別, 大會類別, 類別, 選區, 議員, 質詢內容, 質詢對象, 質詢相關局處,
質詢日期, 議事錄頁碼開頭, 發言開頭2句話, 關鍵字（法案名字、簡稱、地名）
```

範例列：

```
第3屆第5次, 定期會, 市政府業務報告及質詢, 第十選區, 王家貞,
建議市府團隊應詳知公投辦理方法以及內容…, 民政局局長姜淋煌, 民政局,
2021/5/11, p.59, 民政局局長，您來臺南市政府服務多久了？…, 公投、中選會
```

`extract-interpellation.js` 只用其中的 選區、議員、質詢內容、質詢相關局處、質詢日期、議事錄頁碼開頭、發言開頭2句話、編按。「類別」「質詢對象」「關鍵字」目前沒用到。抽樣的這張分頁沒有「編按」欄，程式讀不到時填空字串，其他分頁可能有。

## `content/meta/`（CMS 編輯）

| 檔案 | 內容 |
|---|---|
| `partyList.json` | `{ name, abbr, avatar }`；`abbr` 是議會官網用的簡稱，爬蟲依此對應全名 |
| `departmentBrief.json` | `{ abbr, brief, synonym[] }`；`synonym` 裡的名稱會在抽取質詢時替換成 `abbr`，也會寫成 Algolia 同義詞 |
| `synonym.json` | 一般同義詞（如「台／臺」），寫成 Algolia 同義詞 |
| `misc.json` | 讀分析說明、頁尾連結、`round-list`（頁尾屆次切換，`isDefault` 標預設屆） |
| `about.md` | 關於頁 |

## `content/article/*.md`、`content/setting/article-category-*.json`

文章 frontmatter：`createdAt`、`title`、`slug`、`coverImage`、`category`（分類 slug：`overview` 議員問政速寫、`agenda` 事件議題探討、`tns-review` 新芽議會評論）、`summary`。

## 議事錄 PDF 切片（另一個 repo：`tainan-council-data`）

- 發布網址：`https://tainansprout.github.io/tainan-council-data/interpellation/round/{屆}/{regular}/{第幾次定期會兩位數}/{切片三位數}.pdf`
- 每個切片 10 頁，第 1–10 頁在 `001.pdf`、第 391 頁在 `040.pdf` 的第 1 頁。
- 頁碼就是整本議事錄 PDF 的頁序。實測第三屆 `06/040.pdf` 第一頁頁首印著「第 3 屆 第 6 次定期會 市政總質詢 391」，和頁序一致。
- 製作方式：`cpdf 原檔.pdf -split -chunk 10 -o '…/%%%.pdf'`，再用 `tools/minify-pdf.sh`（ghostscript `/screen`）壓縮。
- 目前只有 `3rd/regular/01`～`06`，git 本體已 1.4 GB。
